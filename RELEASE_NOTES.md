# ShotgunKeyboard 2.1

A small desktop app for macOS and Windows that plays original synthesized effects as you type.

- Select one sound, or enable Multiple sounds to randomize across checked effects.
- Import your own audio files.
- Control volume, Armed mode, and sound tests from the desktop window.
- Open the Mac window from its Dock or menu bar icon; open the Windows window from the taskbar or tray icon.
- macOS downloads are separate for Apple Silicon and Intel. The Windows download is a portable, self-contained EXE.

The builds are unsigned. On macOS, grant Input Monitoring and Accessibility access after installing. Source code and build instructions are in the repository README.
