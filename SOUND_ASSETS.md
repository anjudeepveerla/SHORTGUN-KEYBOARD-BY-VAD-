# Contributed sound assets

The 12 MP3 files in `bundled-sounds/` were supplied by the project contributor, who confirmed permission to redistribute them publicly in this repository and in the macOS and Windows downloads. They are included so everyone who downloads ShotgunKeyboard can use these effects in the app.

The repository's MIT license covers the application source code and original generated WAV sounds. It does **not** grant a general MIT license for the contributed MP3 files. Permission to use or redistribute those MP3 files outside this project must be obtained from their respective rights holders.
